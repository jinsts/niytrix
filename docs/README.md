# Documentation

This directory turns the unified plan into a navigable documentation set. The
HTML document remains the complete reading edition; the Markdown documents are
smaller working views intended for review, discussion, and future refinement.

## Reading paths

### Understand the product

1. [Platform charter](platform-charter.md) — purpose, principles, boundaries, and
   definition of success.
2. [Strategy portfolio](strategy-portfolio.md) — the two mandates and why they
   are not blended.
3. [Risk and governance](risk-and-governance.md) — capital firewall, authority,
   and staged promotion.

### Understand the proposed platform

1. [Platform architecture](platform-architecture.md) — conceptual capabilities,
   isolation boundaries, data flow, and deferred choices.
2. [Evidence and operations](evidence-and-operations.md) — validation chain,
   operating rhythm, and failure behaviour.
3. [Roadmap and open decisions](roadmap-and-open-decisions.md) — discovery order,
   gates, and unresolved questions.

### Read the complete plan

Open [Unified Trading Strategy & Wealth Operating Plan](unified-trading-strategy.html)
in a browser. It includes dark/light themes, responsive navigation, and print/PDF
styling.

## Document roles

| Document | Role | Status |
| --- | --- | --- |
| Unified HTML plan | Consolidated, designed reading edition | Baseline v1.0 |
| Platform charter | Product intent and non-negotiable boundaries | Draft for review |
| Strategy portfolio | Strategy mandates and isolation rules | Draft for review |
| Risk and governance | Capital, authority, and promotion controls | Draft for review |
| Platform architecture | Conceptual design, not an implementation specification | Proposed |
| Evidence and operations | Validation and operational expectations | Proposed |
| Roadmap and open decisions | Ordered discovery backlog | Active |

## Maintenance rule

Material changes should update the relevant focused Markdown document and the
consolidated HTML plan in the same change. Open questions must remain visibly open
until evidence or an explicit decision closes them.
